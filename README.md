# Cryptography Practice

This repository contains **practical cryptography exercises**, implementations, and challenge solutions.

The work explores number theory, modular arithmetic, RSA, Diffie-Hellman, digital signatures, symmetric encryption, and elliptic curves.

The implementations cover point arithmetic, scalar multiplication, key exchange, AES encryption, Curve25519 operations, continued fractions, RSA attacks, and similar cryptographic techniques.

The repository combines complete solutions with smaller experiments that demonstrate individual cryptographic ideas and related methods.
